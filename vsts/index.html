MFR-303

Acid bass line synthesizer.

  • VST3 + Standalone
  • Windows 64-bit
  • Open source (AGPLv3)

A monophonic bass synth in the spirit of the 303. It has the squelching resonant filter, the accent and slide that make acid lines move, and a step sequencer that syncs to your DAW.

  • Diode-ladder style filter, oversampled. Resonance thins the low end the way the original does.
  • Accent and slide. Accents stack up when they come in a row.
  • 16-step sequencer with note, octave, gate, accent and slide per step, plus swing and a randomizer. Or play it from your piano roll.
  • Drive for when clean isn't the point.

INSTALLING

Two ways in.

Each plugin's download page has two files:

  • The installer (…-setup.exe) puts the VST3 in the standard folder and can also install the standalone app. It adds an uninstaller as well.
  • The zip is for doing it yourself. Copy the .vst3 folder into C:\Program Files\Common Files\VST3\.

Then rescan plugins in your DAW. In FL Studio, that's Options › Manage plugins › Find plugins.

QUESTIONS

Before you ask.

Windows says it "protected your PC".

The installers aren't code-signed yet, so Windows SmartScreen doesn't recognise them. Click More info, then Run anyway. If you'd rather skip the installer entirely, use the zip.

Mac? Linux?

Windows only for now. The code is portable, so other platforms are possible later.

Is it really free?

Yes. The plugins are free to use in your music, commercial releases included. The source code is public under the GNU AGPLv3. If you change the code and distribute it, you share your changes under the same licence.

Found a bug, or have an idea?
