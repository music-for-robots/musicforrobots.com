PLUGINS

The rack.

MFR-303

Acid bass line synthesizer.

  • VST3 + Standalone
  • Windows 64-bit
  • Open source (AGPLv3)

A monophonic bass synth in the spirit of the 303. It has the squelching resonant filter, the accent and slide that make acid lines move, and a step sequencer that syncs to your DAW.

  • Diode-ladder style filter, oversampled. Resonance thins the low end the way the original does.
  • Accent and slide. Accents stack up when they come in a row.
  • 16-step sequencer with note, octave, gate, accent and slide per step, plus swing and a randomizer. Or play it from your piano roll.
  • Drive for when clean isn't the point.

MFR-Mayo

Fuzz, amp, and a pickup that sings.

  • Guitar effect
  • VST3 + Standalone
  • Windows 64-bit
  • Open source (AGPLv3)

A 90s-style op-amp fuzz into a cranked British amp, with a cheap microphonic pickup in the loop. Play through it and it's a thick, scooped wall of fuzz. Stop, and the rig starts to whistle.

  • Real feedback, simulated. Nothing triggers the whistle. It builds when your strings stop, jumps between pitches and sags, like the real thing.
  • Squeal controls for how microphonic the pickup is, where the whistle sits, and how much it wanders.
  • Gate first in the chain, so it's quiet when you're not playing, and you decide how long the whistle rings.
  • Amp and cab bypass if you'd rather use your own amp sim.

MFR-Millionaire

C standard without touching the tuning pegs.

  • Guitar effect
  • VST3 + Standalone
  • Windows 64-bit
  • Open source (AGPLv3)

Plays your standard-tuned guitar as if it were tuned down, then runs it through an early-2000s desert-rock rig: a boost, three very different amps blended together, and a cab miked from across the room.

  • Drop tuner, 0 to 12 semitones, with a readout of the tuning you're in. About 9 ms of latency, so you can play through it live, or an HQ mode for re-amping.
  • Three amps in parallel: a scratchy transistor head, a warm valve combo and a wild hybrid.
  • Honk control for that nasal ~600 Hz midrange, and a mic you can pull back into the room.
  • Boost and octave fuzz in front of it all.
DOWNLOAD (Windows) SOURCE CODE

MFR-Whale

Two guitarists, two rigs, one guitar.

  • Guitar effect
  • Stereo
  • VST3 + Standalone
  • Windows 64-bit
  • Open source (AGPLv3)

Your guitar through two different amp rigs at once, one on each side, for a huge double-tracked mid-2000s sludge and prog-metal wall.

  • Left: a valve overdrive pedal into a bright, loose '70s lead head.
  • Right: an '80s head with 6550 power valves, tighter and deeper.
  • Spread from a centred blend to a wide wall that sounds like two separate takes.
  • Level-matched sides, a gate, and effectively zero latency.

INSTALLING

Two ways in.

Each plugin's download page has two files:

  • The installer (…-setup.exe) puts the VST3 in the standard folder and can also install the standalone app. It adds an uninstaller as well.
  • The zip is for doing it yourself. Copy the .vst3 folder into C:\Program Files\Common Files\VST3\.

Then rescan plugins in your DAW. In FL Studio, that's Options › Manage plugins › Find plugins.

QUESTIONS

Before you ask.

Windows says it "protected your PC".

The installers aren't code-signed yet, so Windows SmartScreen doesn't recognise them. Click More info, then Run anyway. If you'd rather skip the installer entirely, use the zip.

Mac? Linux?

Windows only for now. The code is portable, so other platforms are possible later.

Is it really free?

Yes. The plugins are free to use in your music, commercial releases included. The source code is public under the GNU AGPLv3. If you change the code and distribute it, you share your changes under the same licence.

Found a bug, or have an idea?

Open an issue on the plugin's GitHub page: MFR-303, MFR-Mayo, MFR-Millionaire, MFR-Whale.
